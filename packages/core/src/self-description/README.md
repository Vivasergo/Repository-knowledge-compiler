# Self-description boundary

Owns the version-matched, progressively loadable RKC manifest/modules and the
read-only structured help boundary used by `rkc-help`. General answers use the
catalog; action intent returns a route without performing it; project status
reports only validated/observable `.rkc` availability and compatibility.

The catalog derives its capability and support claims from the current V2
implementation and versioned documentation protocol. It does not inspect
arbitrary core source, duplicate provider-specific truth, or mutate
installation and actual repository documentation.
